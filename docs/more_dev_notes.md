Some notes on stuff that should not be necessary for day-to-day development.

Burning bootloader.
I use the Arduino IDE for this. Programmer is connected to the computer with USB and ICSP cable is plugged into the Arduino board. Board is seperately powered by USB. Select Tools -> Port, make sure port for programmer is selected.  Programmer is set to "AVR ISP 500 Olimex" (I think I added this programmer configuration myself).
