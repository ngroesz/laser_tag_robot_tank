# Documentation

There are also relevant documents in the 3d_printing and pcb_design repositories (see
Links section in [main README](../README.md)).

Most of the documents are in this repository. They include:
* [development](development.md) - A guide for developers beginning to
program their own Laser Tag Robot Tank.
* [hardware test](hardware_test.md) - A detailed guide to using the
hardware test sketch to test the various robot functions.
* [sketches](sketches.md) - A description of the various sketches included in
this repository.
* [quickstart](quickstart.md) - How to get the tank to do something interesting,
quickly.
